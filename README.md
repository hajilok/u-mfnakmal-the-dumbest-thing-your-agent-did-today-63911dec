# The Dumbest Thing Your Agent Did Today

Entry for the [make.fun](https://make.fun/r/41fw6r6c) bounty **The Dumbest Thing Your Agent Did Today** (`u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec`).

## Usage

Runs on Node 22+ (`program/v1`) and deterministically writes the single-line UTF-8 entry (`<= 200` characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` locally):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
